# Мой личный навигатор — описание и инструкция

**Ссылка на продукт:** https://moy-navigator.vercel.app

## Что это
Личная система управления жизнью. Она связывает всё в одну цепочку:
**идея → сфера → цель → задача → план дня → выполнение → итог → статистика → корректировка.**
Работает в браузере на телефоне и компьютере (можно поставить на главный экран как приложение).
Все данные лежат в вашем облаке (Supabase) и одинаковы на всех устройствах.

## Разделы
| Раздел | Для чего |
|---|---|
| Сегодня | План дня, подсказки, статус задач, свободное время |
| Входящие | Быстрая запись идей (текст или голос), потом разбор |
| Календарь / Расписание | Любая дата, неделя, месяц, год |
| Задачи | Все дела с фильтрами |
| Цели | Цели и подцели, показатели, связанные задачи |
| Сферы | Семья, деньги, бизнес и т.д. с оценкой 0–10 и графиком |
| Проекты / Контакты | Группировка задач по проектам и людям |
| История | Журнал всех изменений (ничего не пропадает) |
| Статистика | План/факт, % выполнения, баланс времени по сферам |
| Недельный обзор | Раз в неделю: итоги, цели без движения, идеи |
| Итоги дня | Дневник размышлений: 3 вопроса вечером |
| Матрица | Задачи по Эйзенхауэру: выполни / запланируй / делегируй / удали |
| Архив | Удалённое (можно восстановить) |

## Как пользоваться эффективно

**Первый запуск (10 минут).** Зарегистрируйтесь → пройдите мастер: оцените сферы, впишите 1–3 главные цели, укажите рабочие часы. Это основа: без целей и сфер аналитика пустая.

**Каждый день (5 минут утром + 2 минуты вечером):**
1. Утром откройте «Сегодня». Посмотрите «AI-план дня» и нажмите «Принять план». Задачи, которые «не помещаются», перенесите.
2. Читайте подсказки над планом: они предлагают привязать задачу к цели, объединить похожие идеи, разгрузить завтра.
3. В течение дня отмечайте задачи кружком слева. У долгих дел указывайте фактическое время: тогда статистика честная.
4. Вечером (10 минут) откройте «Итоги дня» и ответьте на три вопроса: что прошло хорошо, что прошло не так, что завтра сделаю конкретно по-другому. Ответ на третий вопрос утром появится на «Сегодня».

**Мысль пришла — не думайте, записывайте.** Кнопка-лампочка (или клавиша `I`) есть на каждой странице. Нажали, написали или продиктовали, сохранили. Разбирать будете потом во «Входящих»: «В задачу», «В цель», «Отложить».

**Правило связки.** Создавая задачу, выбирайте сферу и цель. Тогда в целях видно прогресс, а в статистике — куда уходит время.

**Раз в неделю (15 минут).** Откройте «Матрицу»: выполните поле 1, назначьте даты полю 2, делегируйте поле 3, удалите поле 4. «Недельный обзор»: план/факт, цели без движения, неразобранные идеи. Обновите оценки сфер: через месяц увидите динамику. Спланируйте следующую неделю в календаре.

**Полезные приёмы**
- Задача без времени = «на день»; с временем и длительностью попадает в шкалу и свободное время.
- Повторяющиеся дела задаются один раз (каждый день / по будням / раз в месяц…).
- Напоминания: за 5 минут, час, день и т.д.; можно несколько.
- Клавиши: `N` новая задача, `I` идея, `T` сегодня, `/` поиск, `←` `→` день назад/вперёд.
- Поиск ищет по названиям, контексту, результатам, проектам и контактам.
- Ничего не удаляется навсегда сразу: сначала архив.

## Telegram
Напоминания, утренний план, вечерний итог, недельный обзор, напоминания о целях и идеях приходят через бота «Штурман».
Подключение: Настройки → Telegram → введите свой Chat ID (его показывает бот @userinfobot) → «Подключить». Придёт сообщение о подключении.
Вкладка появляется только в облачной версии (по ссылке выше).

## Резервные копии и данные
Настройки → Данные: полный JSON-бэкап, CSV (задачи, цели, сферы, оценки, идеи, история, итоги, статистика), календарь ICS. Рекомендуется делать JSON-бэкап раз в месяц.

## Что важно знать
- Без интернета можно создать задачу или идею и отметить статус: всё отправится при подключении. Остальное офлайн недоступно.
- Кнопки «Выполнено/Перенести» в Telegram не работают (бот Штурман используется без webhook) — есть только ссылка «Открыть задачу».
- Напоминания приходят с точностью до ~5 минут (расписание запускает GitHub Actions).
- Для бота Штурман действует одно ограничение: сообщения приходят только тому, кто уже писал ему.
